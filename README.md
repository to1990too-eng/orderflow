# OrderFlow: Асинхронная микросервисная обработка заказов

Отказоустойчивый сервис обработки заказов, разделенный на независимые микросервисы. Демонстрирует навыки работы с асинхронным Python (asyncio), брокерами сообщений (RabbitMQ), фоновыми задачами и контейнеризацией.

## 🏗 Архитектура

Проект состоит из трех независимых сервисов:
1. **`auth_service`** (порт 8001) — регистрация и выдача JWT-токенов.
2. **`order_service`** (порт 8002) — создание заказов. При создании отправляет событие в RabbitMQ.
3. **`notification_service`** (без публичного API) — слушает RabbitMQ, имитирует отправку Email и обновляет статус заказа через HTTP-запрос.

**Стек:** Python 3.11, FastAPI, SQLAlchemy 2.0 (async), PostgreSQL, RabbitMQ, aio-pika, Docker, pytest.
